# 常见问题（FAQ）

## 把结果复制到微信 / QQ 后排版歪了？

多半是**半格块字符**（`▀▄█`）造成的。它们的 East Asian Width 是 **Ambiguous**：
纯西文环境按 1 列算，部分中文环境按 2 列算，整幅画会被横向拉伸。

拼字与图案都提供 `symbol` 风格（纯窄字符），宽度绝对安全。卡片上会标注风险，改用那个即可。

## 为什么有些字符显示成方块（豆腐块）？

因为你的设备缺少对应字形。项目内置校验器，会拦截私有使用区和冷门文字区的字符并给出提示。
若仍遇到方块，欢迎提 Issue，附上字符和你的设备/系统环境。

## 不配置 AI 能用吗？

能，而且是完整功能。AI 默认关闭，关闭时全流程零模型调用 —— 规则版词库负责把「人话」翻译成意图。

## 配置了 API Key，安全吗？

Key 存在浏览器本机的 `localStorage`，只适合个人本机使用。
若要公开部署，不要把 Key 打进前端 —— 那需要一个服务端代理来中转。

## AI 会不会直接生成颜文字？

不会。模型只做一件事：把自然语言翻译成结构化 JSON 意图。
颜文字本身永远由确定性工具产出，因此输出可校验、可复现、可回退。

## 支持哪些输入？

以中文为主，也认一部分英文与 emoji 同义词，例如「开心 / happy / 😄」「猫 / cat / 🐱」「晚安 / good night」。
要拼字就写「拼一个喜」「用符号写 OK」。

## 怎么添加自己喜欢的颜文字或零件？

编辑 `src/data/kaomoji.ts`（成品库）或 `src/data/parts.ts`（组件库），规则见 [CONTRIBUTING.md](./CONTRIBUTING.md)。

## 怎么部署？

纯静态站点。`npm run build` 后把 `dist/` 交给任意静态托管即可。
